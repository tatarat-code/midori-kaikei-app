# ミドリ商事 財務会計アプリ（演習用）

> **これは研修用の教材です。**
> 実在の企業・団体とは一切関係ありません。
> 記載されている数値・勘定科目・従業員数はすべて架空のものです。

---

## このアプリについて

株式会社ミドリ商事（架空）で使われている、部門別の費用管理アプリです。

AppSheet で画面を作り、計算処理を Google Apps Script（GAS）で書いています。
経理担当者が毎月の共通費を各部門に振り分け、集計表を出力するために使っています。

## 会社の設定（架空）

| 項目 | 内容 |
|---|---|
| 会社名 | 株式会社ミドリ商事 |
| 事業内容 | 食品の卸売 |
| 従業員数 | 25名（営業部門15名／管理部門10名） |
| 部門 | 営業部門、管理部門 の2部門 |

## ファイル構成

| ファイル名 | 内容 |
|---|---|
| `README.md` | このファイル |
| `requirements.md` | **要件定義書**（経理課長が作成した仕様書） |
| `code/allocation.gs` | 按分計算 ── 共通費を部門に振り分ける処理 |
| `code/tax.gs` | 消費税計算 ── 消費税額を計算する処理 |
| `code/report.gs` | 集計出力 ── 集計表を出力する処理 |

> 拡張子 `.gs` は Google Apps Script のファイルです。
> 中身はJavaScriptで書かれているため、そのまま読むことができます。

## 演習の進め方

配布された **`midori-kaikei-app_kyozai.md`** を使います。
このファイル1つに、要件定義書とコードがすべて入っています。

1. Gemini で **新しいチャット** を開く
2. 入力欄の **「＋」** をクリック
3. **「ファイルをアップロード」** を選ぶ
4. `midori-kaikei-app_kyozai.md` を選ぶ
